SOFTDENT — VERSIÓN 9: CORRECCIONES DE SONARQUBE CLOUD (22 de noviembre)

Corrige los 107 hallazgos del primer análisis de SonarQube Cloud (106 de fiabilidad y 1 de seguridad).
Se copia encima de lo que hoy está en main: 42 archivos (41 modificados y 1 nuevo, lib/texto.ts).
No necesita SQL ni "npm install".

IMPORTANTE: borra el LEEME.txt que quedó subido en main (ver los pasos abajo).

QUÉ SE CORRIGIÓ
 · 68  Etiquetas de formulario sin campo asociado: cada etiqueta queda unida a su campo
       (al hacer clic en la etiqueta se enfoca el campo, y los lectores de pantalla la leen).
 · 13  Elementos con clic que no eran botones: el fondo de los modales, las celdas de la grilla
       de agenda, el número de pieza del odontograma y la tarjeta de cita ahora son botones
       o se pueden usar con teclado.
 ·  7  Botones sin "type": se agregó type="submit".
 ·  7  Expresiones regulares lentas (riesgo de bloqueo con textos maliciosos): reemplazadas por
       funciones de costo lineal en lib/texto.ts (quitar etiquetas HTML, validar correo,
       formatear RUT con puntos).
 ·  7  Promesas sin manejo de error: ahora registran el error en consola.
 ·  2  Ordenamientos de texto sin comparador: usan localeCompare.
 ·  1  Uso de "http": cambiado a "https".
 ·  1  tabIndex en un elemento no interactivo: los términos del glosario ("?") son botones.
 ·  1  autoFocus: eliminado del buscador de pacientes al agendar.

CÓMO SUBIRLO (terminal de VS Code, en la carpeta softdent-final)
  1. Copiar el contenido del ZIP encima del proyecto (reemplazar archivos).
  2. git rm LEEME.txt
  3. npm run build
  4. git add -A
  5. git commit -m "Correcciones SonarQube"
  6. git push origin main
  SonarQube Cloud analiza solo el nuevo push. En unos minutos se ve el resultado nuevo.
